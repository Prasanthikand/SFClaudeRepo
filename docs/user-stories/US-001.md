---

User Story: US-001
Description: As a Salesforce Administrator, I want to automatically delete Task records that are marked as Completed and older than one year, So that the system remains clean, optimized, and free from unnecessary historical data.
---
Acceptance Criteria: 
An Apex Batch Class exists that:
    - Queries Task records where Status = Completed.
    - Filters records with ActivityDate < Today − 365 days.
    - Deletes those records in batch execution.
    - The batch is scheduled to run daily at 3:00 AM.
    - The batch handles large volumes of records efficiently without hitting governor limits.
